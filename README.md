# Anglis — Cuidado sem Vigilância

> Documentação completa do projeto Anglis: estratégia, posicionamento, campanha "Cada Segundo Conta" e modelo comercial, desenvolvido pelo time **Outliers**.

## 🔗 Links do projeto

- **Site institucional:** [anglis-site.vercel.app](https://anglis-site.vercel.app/)
- **Landing Page (campanha):** [anlgis-lp.vercel.app](https://anlgis-lp.vercel.app/)
- **Apresentação (Canva):** [link do Canva](https://canva.link/zec3f3jqcokpz48)

## 📖 Sobre

Este repositório contém a página de documentação (`index.html`) que reúne toda a estratégia do projeto Anglis, incluindo:

- O problema de posicionamento identificado
- O insight estratégico ("cuidado sem vigilância")
- A campanha **#CadaSegundoConta**
- A jornada do lead, do evento físico à conversão
- O modelo comercial (planos Base, Cuidado e 360)
- Investimento e métricas (CPL, CAC)

## 🛠️ Tecnologia

Página estática em **HTML + CSS puro**, com [Tailwind CSS](https://tailwindcss.com/) via CDN para utilitários pontuais. Sem frameworks, sem build step.

## 🚀 Deploy

Hospedado na [Vercel](https://vercel.com/). Qualquer push na branch `main` gera um novo deploy automaticamente.

```bash
git clone https://github.com/SEU-USUARIO/anglis-documentacao.git
cd anglis-documentacao
# abra o index.html direto no navegador para visualizar localmente
```
